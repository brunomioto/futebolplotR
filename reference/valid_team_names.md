# Output Valid Brazilian Soccer Team Abbreviations

Output Valid Brazilian Soccer Team Abbreviations

## Usage

``` r
valid_team_names()
```

## Value

A vector of type `"character"`.

## Examples

``` r
# List valid Brazilian soccer team abbreviations
valid_team_names()
```
