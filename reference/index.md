# Package index

## Geoms

ggplot2 geoms (geometric objects) that create a
[`layer()`](https://ggplot2.tidyverse.org/reference/layer.html). A layer
combines data, aesthetic mapping, a geom (geometric object), a stat
(statistical transformation), and a position adjustment.

- [`geom_futebol_badges()`](https://brunomioto.github.io/futebolplotR/reference/geom_futebol_badges.md)
  : ggplot2 Layer for Visualizing Brazilian Soccer Team badges

## Scales

Scales control the details of how data values are translated to visual
properties. Override the default scales to tweak details like the axis
labels or legend keys, or to use a completely different translation from
data to aesthetic.

- [`scale_color_futebol()`](https://brunomioto.github.io/futebolplotR/reference/scale_futebol.md)
  [`scale_colour_futebol()`](https://brunomioto.github.io/futebolplotR/reference/scale_futebol.md)
  [`scale_fill_futebol()`](https://brunomioto.github.io/futebolplotR/reference/scale_futebol.md)
  : Scales for Brazilian Soccer Team Colors

## Theme Elements

Themes control the display of all non-data elements of the plot. Theme
elements can tweak individual settings inside
[`theme()`](https://ggplot2.tidyverse.org/reference/theme.html).

- [`element_futebol_badge()`](https://brunomioto.github.io/futebolplotR/reference/element.md)
  : Theme Elements for Image Grobs

## Utilities

Various helper functions.

- [`clean_team_abbrs()`](https://brunomioto.github.io/futebolplotR/reference/clean_team_abbrs.md)
  : Standardize Brazilian Soccer Team Abbreviations
- [`valid_team_names()`](https://brunomioto.github.io/futebolplotR/reference/valid_team_names.md)
  : Output Valid Brazilian Soccer Team Abbreviations
- [`futebol_team_abbr_mapping`](https://brunomioto.github.io/futebolplotR/reference/futebol_team_abbr_mapping.md)
  : Brazilian Soccer Team Abbreviation Mapping
- [`teams_colors_badges`](https://brunomioto.github.io/futebolplotR/reference/teams_colors_badges.md)
  : Brazilian Soccer Team Names and Colors
