# futebolplotR: Brazilian Soccer Badges Plots in 'ggplot2'

A set of functions to visualize Brazilian Soccer analysis in 'ggplot2'.

## Usage

``` r
GeomFUTbadge
```

## Format

An object of class `GeomFUTbadge` (inherits from `Geom`, `ggproto`,
`gg`) of length 5.
